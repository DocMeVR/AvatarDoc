## Requirements [#requirements]

- Unity 2022.3
- VRChat SDK 3.10 or newer
- NDMF 1.14.1 or newer

NDMF comes from its own listing, by its author bd_. Add it next to the DocMe listing once, and VCC installs NDMF together with AvatarDoc.

## Install with VCC [#install-with-vcc]

<Steps>

1. Add the DocMe listing to VCC. Select <a href={site.vccAddUrl}><strong>Add to VCC</strong></a>, or add <code>{site.listingUrl}</code> as a repository in VCC. The <a href={site.listingPage}>listing page</a> has the same link.

2. Add the NDMF listing the same way. Select <a href={site.ndmfVccAddUrl}><strong>Add to VCC</strong></a>, or add <code>{site.ndmfListingUrl}</code>. The DocMe listing page has a second button for it. If you use Modular Avatar, this listing is in VCC already.

3. Open your avatar project and select **Manage Project**.

4. Find **DocMe AvatarDoc** in the list and add it. VCC adds NDMF with it.

</Steps>

## Without VCC [#without-vcc]

<details>
<summary>Install from a file</summary>

Install NDMF first. Then download the release zip from the <a href={site.releasesUrl}>releases page</a> and unpack it into `Packages/dev.docme.avatar-doctor` in your project. You can also import the unitypackage from the same page.

</details>
