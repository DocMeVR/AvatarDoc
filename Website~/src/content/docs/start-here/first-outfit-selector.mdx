At the end of this page your avatar menu has an Outfits submenu. Pressing an outfit in it shows that outfit and hides the others.

## Before you start

- An AvatarDoc component on your avatar, as in [Your first toggle](../first-toggle/).
- The inspector in <Label k="ad.ui.mode.advanced" /> mode, the default. [Simple or Advanced?](../simple-or-advanced/) explains the modes.
- Two or more outfit objects on the avatar. This page uses Jacket, Hoodie and Shoes.

## Steps

<Steps>

1. In the Hierarchy, select the object that holds your AvatarDoc component.

2. In the inspector's toolbar, press <Label k="ad.ui.more" />, then <Label k="ad.ui.add.outfit" />.

   You should now see the <Label k="ad.ui.outfit.title" /> window.

3. In the window, type `Outfits` into <Label k="ad.ui.outfit.name" />. This becomes the submenu's name.

4. In the Hierarchy, select Jacket, Hoodie and Shoes. Hold Ctrl (Cmd on a Mac) while you click to select more than one.

5. Drag the three objects onto <Label k="ad.ui.outfit.drop" /> in the window.

   You should now see two buttons: <Label k="ad.ui.outfit.split.each" /> and <Label k="ad.ui.outfit.split.all" />.

6. Press <Label k="ad.ui.outfit.split.each" />.

   You should now see three outfit cards, Jacket, Hoodie and Shoes, each holding its own object. On the first card, the <Label k="ad.ui.outfit.default" /> chip is highlighted: that outfit is on when the avatar loads. If a card lists <Label k="ad.ui.outfit.shrinks" />, leave them unticked for now.

   <Shot name="start-here/first-outfit-window" alt="The Outfit set window with 1 the set name Outfits, 2 the Jacket, Hoodie and Shoes outfit cards, and 3 the Create outfit set button." />

   In the picture, 1 is the set name, 2 the three outfit cards and 3 <Label k="ad.ui.outfit.create" />.

7. Press <Label k="ad.ui.outfit.create" />.

   You should now see the window close. With <Label k="ad.ui.outfit.capture" /> on, AvatarDoc also makes a menu icon for each new entry.

8. In the Hierarchy, select the object that holds your AvatarDoc component again.

   You should now see the new Outfits submenu selected in the tree.

9. In the tree, press the arrow beside Outfits.

   You should now see the Jacket, Hoodie and Shoes toggles inside it.

</Steps>

## Test it

With Gesture Manager in Play mode, as in [Your first toggle](../first-toggle/#test-it), open **Expressions**, then **Outfits**, and press **Hoodie**. The hoodie shows and the jacket hides. The jacket is on at the start, because it is the default outfit.

Without Gesture Manager, upload the avatar and use the Outfits submenu in VRChat's Expressions menu.
